## 新建最小 Vite+TS 项目：单元测试 + 视觉快照 + 格式化管理

### 摘要

在空目录 `F:\tools\test\PJ1` 用 Vite `vanilla-ts` 模板初始化项目，保持无框架、无外部静态资源的最小形态。选型如下：

- 构建与类型检查：Vite + TypeScript（strict、`noEmit`）。
- 单元测试：Vitest，`node` 环境，只测纯 TypeScript 逻辑，零额外浏览器依赖。
- 视觉快照：Playwright `@playwright/test`，用 `expect(page).toHaveScreenshot()` 生成并比对 PNG 基线。
- 格式化管理：Prettier（`format`/`format:check` 脚本）+ `.prettierrc.json` + `.prettierignore` + `.editorconfig`。
- 包管理器：npm（本机 pnpm/yarn 的 nvm 包装不可用）。

演示页保持确定性渲染：一个标题 + 一个计数器按钮，纯系统字体、无动画、无外部资源，保证快照稳定。

### 关键改动

- 用 `npm create vite@latest . -- --template vanilla-ts` 初始化，安装开发依赖：`vitest`、`@playwright/test`、`prettier`。
- 业务代码拆成两层：`src/counter.ts` 提供纯函数 `createCounter(initial)`（`getValue`/`increment`/`decrement`/`reset`），`src/main.ts` 负责挂载 DOM 并更新计数显示；`index.html` 和 `src/style.css` 呈现一张固定尺寸卡片。
- `vite.config.ts` 使用 `vitest/config` 的 `defineConfig`，在其中内联 `test` 配置，避免额外配置文件；Vitest 默认 `node` 环境。
- 新建 `playwright.config.ts`：固定视口 `800x600`、`reducedMotion: 'reduce'`，用 `webServer` 自动启动 `vite dev`（`127.0.0.1:5173`），快照目录设为 `tests/e2e/__snapshots__`；使用 Playwright 管理的 Chromium（一次性执行 `npx playwright install chromium`），保证跨机器快照一致。
- `tsconfig.json` 采用 strict 模式、`noEmit: true`，`build` 脚本为 `tsc --noEmit && vite build`。
- `package.json` 脚本：
  - `dev`：启动 Vite 开发服务器
  - `build`：类型检查 + 构建
  - `preview`：预览构建产物
  - `test`：`vitest run`
  - `test:watch`：`vitest`
  - `test:e2e`：`playwright test`
  - `test:e2e:update`：`playwright test --update-snapshots`
  - `format`：`prettier --write .`
  - `format:check`：`prettier --check .`
- 新增 `.gitignore`，忽略 `node_modules/`、`dist/`、`test-results/`、`playwright-report/`；快照 PNG 基线需提交进仓库。

### 测试方案

- 单元测试：`src/counter.test.ts` 覆盖初始值、递增、递减、重置，验证纯逻辑不依赖 DOM。
- 视觉快照：`tests/e2e/app.spec.ts` 加载首页，固定视口与字体，对初始状态截图；另加一个交互用例，点击按钮后断言计数文本变化并再截图。
- 基线流程：首次执行 `npm run test:e2e:update` 生成基线并提交；后续 `npm run test:e2e` 做像素比对，差异时报告并生成 diff 到 `test-results/`。
- 验收标准：`npm run build`、`npm test`、`npm run test:e2e`、`npm run format:check` 全部通过。

### 假设与默认

- 不做 WebGPU、不引入 UI 框架；这是纯 Vite+TS 最小项目。
- 不接入 husky/lint-staged 等提交钩子，格式化通过 `format` 脚本和编辑器保存时格式化完成，保持 v1 最小；后续需要再补。
- 视觉快照统一使用 Playwright 管理的 Chromium 以保证可复现；系统 Chrome 仅作为离线备选，不作为默认。
